name: Optimizer control visibility
description: Preserve discoverability of setup controls during responsive visual changes.
---
The user requested an optimizer visual revamp, not hiding the existing controls behind tabs on laptops.

**Why:** The user reported their controls missing after a responsive change hid Pro setup on the Players tab and moved the standard laptop setup into a separate tab.

**How to apply:** Keep Pro setup visible in normal Players and Lineups views, and keep the standard laptop setup panel visible alongside players. Full-screen player focus should remain an explicit user action.
